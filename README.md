🛍️ React Weather App
Простое приложение с погодой, можно посмотреть погоду в любом городе мира, влажность, температуру и тд.

🚀 Запуск проекта
git clone https://github.com/Mouse-te10/react-weather.git npm i npm run start

💻 Технологии
React ReactDOM CSS Javascript HTML Git
